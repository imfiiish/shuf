# 抽样逻辑：单层活跃窗口

> 本文描述 Study 页「一轮」的抽词逻辑。
> 当前参数：**W = 4R；n 默认 6 / 更快学新词 4 / 更多复习 8**。
> R（每轮张数）在设置里选 8 或 16，于是 W = 32 或 64。
> 只有这一层窗口，没有外围的级联层。

## 1. 要解决的问题

「整池洗牌取前 R 个」每轮独立均匀，同一个词隔多久再见 ≈ N/R 轮，池子越大越碰不到老词：

| 池子 N | 每词每轮出现率 R/N | 相邻两轮 ≥1 个重复 | 隔多少轮再见同一词 |
|---:|---:|---:|---:|
| 50 | 32% | 99.96% | 3 轮 |
| 2000 | 0.80% | 12.1% | 125 轮 |
| 10000 | 0.16% | 2.5% | 625 轮 |

目标：**不管 N 多大，都让最近学的词保持稳定、够高的重复率**（熟悉感），同时长期又能覆盖全部词。

做法很简单：维护一个只有 `W` 个词的**活跃窗口**，每轮从窗口里抽 `R` 个；窗口每隔 `n` 轮从整个词池重新抽一次。不再有更大的中间层。

## 2. 参数

| 符号 | 值 | 含义 |
|---|--:|---|
| `R` | 8 \| 16 | 每轮张数（设置里选） |
| `W` | `4R` = 32 \| 64 | **活跃窗口**（每轮实际从这 `W` 个里抽） |
| `n` | 6 / 4 / 8 | 活跃窗口寿命（轮）：默认 / 更快学新词 / 更多复习 |
| `N` | 当前词池大小 | 窗口到期时从这里整窗重抽 |

## 3. 公式

1. **窗口内每词每轮出现概率**

   ```
   P = R / W = 16 / 64 = 25%
   ```
   因为 `W = 4R`，任何 R 下都是 25%。

2. **一个窗口寿命内，每词平均出现次数**

   ```
   k = n · R / W = n / 4
   ```
   默认 `n=6` → 1.5 次；更快 `n=4` → 1 次；更多复习 `n=8` → 2 次。

3. **窗口刷新周期**

   ```
   T = n 轮
   ```

4. **全局平均每词出现率**

   ```
   R / N
   ```
   窗口只改变出现的时间分布（把重复聚成堆），不改变长期平均覆盖率。

5. **覆盖速度**

   ```
   每 n 轮引入 W 个（重新抽到的）词，平均每轮约 W / n 个新面孔
   ```
   R=16（W=64，n=6）约 10.7 个/轮；R=8（W=32，n=6）约 5.3 个/轮。

## 4. 算法

```
初始化:
  window = 从整个池 N 里均匀随机抽 W 个

每一轮 t:
  if t > 0 且 t % n == 0:          # 窗口到期
    window = 从整个池 N 里均匀随机抽 W 个
  round = window 洗牌取 R 个
```

窗口内的词在 `n` 轮里保持不变，所以相邻两轮会大量重叠；到期后整窗换新，开始下一批。

## 5. 时间线示例（n=6）

```
t=0    从 N 抽 64，得到 round 0
t=1    window 不变，从这 64 个里抽 16
...
t=5    window 不变
t=6    window 到期，从 N 重抽 64，得到 round 6
t=7    window 不变
...
t=12   再次换窗
```

## 6. 调参指南

| 想改什么 | 调哪个 |
|---|---|
| 重复率（窗口内锁多少） | 固定 25%（`W = 4R`） |
| 覆盖速度 / 新旧取舍 | `n`：默认 6 / 更快 4 / 更多复习 8（设置里的「复习 vs 新词」） |
| 每轮张数 | `R`：8 或 16（窗口随之变成 32 或 64） |

> 注意：全局平均每词出现率永远是 `R/N`；窗口只决定「什么时候扎堆出现」。
